🎃 Trick or Trust

Every Approve button is a door. Some have ghosts behind them.

When an AI coding agent asks "Run this command?", the person at the keyboard is the last line of defense. Trick or Trust practices that moment inside Kiro, on the real approval screen, and keeps score.

Built for Kiroween 2026, Skeleton Crew: one small skeleton, two apps.

▶ Watch the demo video (under 3 minutes)

One skeleton, two apps

PartWhat it does
ghostkitThe skeleton. A small policy engine for Kiro hooks, Python standard library only. Reads a hook event, applies TOML rules, answers allow / ask / block, logs it, and builds a report.
Haunted HousePractice rooms. Each room is a tiny project that hides one harmless trap behind an ordinary task. When the trap reaches the approval screen, a ghost is standing next to it.
Night WatchThe same engine in an everyday project. Asks before curl | sh, chmod 777, rm -rf; blocks turning off TLS verification; audits over-broad permissions and credit-hungry setup.

What you see

You ask Kiro to do something ordinary, such as "Set this project up by following the README". Kiro proposes a command. The approval prompt carries a ghost and the exact command. You read, then choose Allow or Deny. Afterwards, the graveyard shows what you did.

See a sample graveyard (sample data, not a real player)

Try it

python3 ghostkit/install.py apply apps/haunted-house/rooms/01-fake-analytics --yes
# open that folder in a new Kiro window, trust it, then ask:
#   Run the analysis script and summarize the result.
python3 ghostkit/report.py apps/haunted-house/rooms/01-fake-analytics/.ghostkit/events.jsonl -o graveyard.html

Harmless by construction

Traps only reach .invalid hosts, which never resolve. Every secret in a room is fake. While a room is in training mode, ghostkit blocks a command that contains a URL for a real host or a real secret path.
